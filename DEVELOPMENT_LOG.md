     - On fast Nyquist clipped overshoots (`04 - Stadium Arcadium` L): 16x Kaiser Sinc = `+1.3155 dBTP`, `ebur128` 4x = `+1.3063 dBTP` (`0.009 dB` error), legacy app = `+1.05 dBTP` (`-0.265 dB` underestimate).

### 10. Review Notes — Open Caveats (honest status)
- **True Peak:** The 16x sinc check was only run in the neighborhood of the peak `ebur128` reported. It confirms `ebur128` is close to the true value there, and that legacy reads low at that spot. It does **not** search the whole file.
- **LUFS `~-0.05 LU` legacy offset:** `ebur128` hits the `-20 dBFS / 997 Hz` calibration sine within `0.003 LU`. The claim that legacy is "biased" is an **inference**: legacy has not yet been run on the same calibration sine. Next step: render that sine to a WAV, run both apps on it, and compare.
- **Min. PSR:** On sparse/dynamic material, results still differ from legacy by up to `~1.8 dB` (e.g. Eldorado Overture `9.12` vs `7.96`). There is no published reference algorithm to settle this, so the cause is **unresolved**. Our version (same `[t-3s, t]` window for peak and Short-Term, `-70 LUFS` gate) is internally consistent, but has not been proven more correct.
- **DR tie case:** `05 - Hump de Bump` has an unrounded DR of `5.5046`, so it rounds to `6`. Legacy reports `5`, which is consistent with it averaging channel values rounded to 2 decimals (`5.31` and `5.69`) in single precision, which can give `4.9999…`. Album DR is unaffected (5/5 match). The per-track joint-DR assertion was relaxed to a per-channel `±0.015 dB` check.
- **Block size at non-44.1k-family rates:** `3 * sr` (48 kHz family) and `3 * (sr + 60·k)` (88.2k/176.4k) are extrapolated. No reference logs exist yet at those rates.
- **Per-channel "non-ITU" Mom/ST on surround** reuses the stereo dual-mono `+3.01 dB` convention for every channel. This is a convention choice, not part of BS.1770.
